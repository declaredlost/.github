# .github

Organization profile and shared community health files for
[Declared Lost](https://github.com/declaredlost).

| Path | Contents |
|---|---|
| [`profile/README.md`](profile/README.md) | The profile shown on [github.com/declaredlost](https://github.com/declaredlost) |
| [`ISSUE_TEMPLATE`](ISSUE_TEMPLATE) | Issue forms for bug reports and feature requests |
| [`pull_request_template.md`](pull_request_template.md) | The default pull request description |

GitHub uses these files for every repository in the organization that does not
have its own copy.
